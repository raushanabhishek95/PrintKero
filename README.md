**PrintKero** is a next-generation, cloud-based QR code document printing and queue management system built specifically for Xerox shops, print stores, and cyber cafes. It eliminates the traditional hassle of transferring files via WhatsApp or filling up phone storage.

## 🚀 Live Demo & Access
* **Official Website:** [https://printkaro.site](https://printkaro.site)

---

## ✨ Key Features

* **🖲️ Counter QR Code Standee:** Customers can instantly scan the shop's custom QR code with their smartphone camera and upload documents directly without needing any third-party app download.
* **☁️ Zero Storage Clutter:** No need to clutter your shop PC or phone gallery with random PDFs and images. Files stream directly from a secure cloud dashboard.
* **📊 Auto Page Counter:** Automatically detects total pages in uploaded PDFs and calculates bills dynamically based on custom B&W or Color rates set by the shop owner.
* **🎫 Live Token Queue System:** Manages rush hours seamlessly by organizing incoming print orders into a sequential digital token queue.
* **🔒 "One View" Privacy:** Customers can set files to self-destruct from the cloud immediately after printing for enhanced data security.

## 🛠️ Tech Stack & Architecture

* **Frontend:** HTML5, Modern CSS, Tailwind CSS (Responsive UI)
* **Icons & UI Effects:** FontAwesome, Custom CSS Animations
* **Backend & Database:** Supabase (PostgreSQL Database & Real-time Client Authentication)
* **Hosting & Deployment:** Vercel
